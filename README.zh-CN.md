# DSH Simple UI

面向 DeepSeek Harness（dsh）Web 客户端的外观皮肤插件：6 套预设、13 种顶栏风格、17 种输入框风格，加上圆角、背景媒体（图片 / 动图 / 视频）、主色 / 中性色 / 字体色、中英文字体的独立定制，全系支持浅色与深色两套配色。所有设置保存在浏览器本地，刷新与重启后仍在；不加载任何网络字体，离线可用。

仓库：<https://github.com/Trouvaille-xx/dsh-Simple-UI>

## 功能

设置页分成 **样式 / 顶栏 / 输入框 / 背景 / 配色 / 字体** 六个标签页。

- **样式**：6 套预设（`[CC]`、Apple 银灰、夜之城 2077、红白页、报纸版面、素描线稿）+ 圆角风格（直角 / 小圆 / 标准 / 大圆 / 超大，另有 0–240% 滑杆；100% 为宿主原生圆角）。
- **顶栏**：13 种会话顶栏风格，分三类：
  - 静态（6）：极简、品牌横幅、深色顶栏、浮动卡片、网格纸、左侧竖条
  - 动态（6）：极光、全息虹彩、蓝图、霓虹赛博、液态金属、星轨
  - 自定义（1）：上传图片，按 16:1 裁切，自动加蒙版
- **输入框**：17 种输入框风格，分三类：
  - 静态（7）：极简扁平、描边卡片、悬浮层、内嵌下沉、终端方角、纸感、玻璃拟态
  - 动态（9）：流光边框、呼吸光晕、极光渐变、霓虹扫描、飘雪、桃花飘落、枫叶飘落、细雨、光标律动
  - 自定义（1）：上传图片，按 6:1 裁切，自动加蒙版
- **背景**：支持静态图片、动图（GIF / APNG）与视频（MP4 / WebM）。媒体存在浏览器 IndexedDB 里（不受 localStorage 配额限制），可一键开关、清除，也可恢复默认。视频默认静音、循环、自动播放，切到后台自动暂停。
- **文件夹轮播**：选一个文件夹当幻灯片源，按文件名自然排序（`1.jpg, 2.jpg, 10.jpg`），切换间隔 5–300 秒可调，支持上一张 / 下一张；文件夹里的视频会被跳过；若目录选择框不可用，可用「多选图片」兜底。最多收录 80 张、总计 200MB，超出部分会提示。轮播状态、当前张数与间隔都会持久化，刷新后接着播。
- **可读性**（背景页）：`遮罩强度` 0–100% 控制盖在图片上的那层膜；`面板不透明度` 0–100% 控制侧栏 / 会话区那层底色的浓淡（0% 完全透明、100% 盖住背景）；`遮罩色调` 可选跟随主题 / 浅色 / 深色。纱罩只上在四个网格单元上，不会因为嵌套叠加把图片彻底盖死。弹窗与设置面板始终保持实心底。
- **配色**：主色、中性色、字体颜色三行独立配置；每行第一个色块是自由取色面板，其余为预设色板。
- **字体**：中文与英文字体分别配置；全部走本地字体栈，缺失时用同风格本地近似兜底，中文不会缺字。
- **深色模式**：所有预设与风格都提供浅色 / 深色两套值，跟随 DSH 主题自动切换，无需手动配置。
- **减少动态效果**：所有 CSS 动画都包在 `prefers-reduced-motion: no-preference` 内，系统开启该设置时动画自动关闭。
- 设置持久化在 `localStorage`（键 `dsh-simple-ui.preset.v1`，含上次所在标签页），背景与自定义图片媒体在 IndexedDB（库 `dsh-simple-ui`），刷新和重启后自动恢复。
- 不引用任何 CDN 或网络字体：首屏零网络阻塞，断网也能正常显示。
- **抗宿主升级**：不写死构建哈希类名。输入框与顶栏优先使用宿主自己挂的语义属性（`header[data-window-drag]`、`[data-conversation-tabs]`、`[data-composer-card]`、`[aria-selected]` 等），其余用 CSS Module 局部名后缀匹配（`[class*="_sidebarCol"]`、`[class*="_centerCol"]`）。DSH 重新构建后哈希变了也照样生效；实在不生效时，背景页有「检测」按钮，直接显示命中了几个宿主容器。
- 通过 DSH 真实 API 下发主题 token（`theme.overrideTokens`），不改写宿主组件，不替换会话渲染器。

## 安装

本插件是 DSH profile 的 bundle，装好后在 **设置 → 外观皮肤**。下面四种方式任选其一，都走 DSH 自带的插件安装能力，不要手改 profile 的 `package.json` / `cordis.patch.yml`。

**方式一：对话里让 Agent 装（最快）**

```text
用 plugin_manager 的 install_bundle 安装 dsh-simple-ui，target 用
git+https://github.com/Trouvaille-xx/dsh-Simple-UI.git#v1.2.0
```

**方式二：插件市场**

在 **设置 → 插件 → 发现** 添加索引源：

```text
https://raw.githubusercontent.com/Trouvaille-xx/dsh-Simple-UI/main/market/index.json
```

然后搜「Simple UI」一键安装。GitHub 直连不通时可用镜像前缀 `https://gh-proxy.com/` 加到同一地址前。

**方式三：离线包**

下载 [Release](https://github.com/Trouvaille-xx/dsh-Simple-UI/releases) 里的 `dsh-simple-ui-<版本>.zip`，解压后把目录绝对路径交给 `plugin_manager` 的 `install_bundle`（`dsh-simple-ui-<版本>.tgz` 则是 `pnpm add file:<路径>`）。

**方式四：已在本地有源码时**

```text
用 plugin_manager 的 install_bundle，target 传 <仓库目录绝对路径>
```

装完重启 DSH 让清单信息（图标、显示名）生效，再打开 **设置 → 外观皮肤**。

说明：`lib/client.js` 这类实现文件的改动会被宿主热载；`package.json`（含展示名、图标、exports）的改动要重启进程才生效，因为宿主只在插件条目启动时读 manifest。

## 数据与隐私

- 不保存、不渲染 API Key。
- 皮肤设置与背景图只存在本机浏览器的 `localStorage`，不发送给模型，也不写入会话。
- 不序列化宿主内部对象。

## 开发

纯 JavaScript 双面插件（无构建步骤）：

- `lib/index.js`：Host 半侧（仅声明，`apply` 为空）
- `lib/client.js`：浏览器 Client 半侧，`window.__ModuleLoader__.load({ id: "dsh-simple-ui", factory })`
- `cordis.patch.yml`：bundle patch，把插件行插进宿主组合
- `locale/zh.json`、`locale/en.json`、`icon.svg`：插件列表里的展示名、描述与图标

语法自查：

```powershell
node --check lib/client.js
```

行为回归（在 Node 沙箱里真实执行 `lib/client.js` 的工厂，注入假的 theme / slots / React / DOM）：

```powershell
node D:\A-AgentWorkspace\09\dsh-simple-ui-tests\client.test.mjs
```

该用例覆盖：工厂身份、设置分区注册、8 个预设逐个应用、颜色图层不泄漏、设置跨重载恢复、卸载清理、无网络字体引用、宿主选择器占位符可解析、CSS 结构合法。

## 背景图怎么选（重要）

插件只能调「遮罩 + 面板底色」，选错图再怎么调都难受。**适合做 UI 背景的图，特征是"暗、虚、空"**；不适合的是"亮、花、满"——樱花、竹林、雪景这种高细节高亮度照片，会把文字彻底吃掉。

给 AI 生图 / 找图时的要求：

- 16:9，2560×1440 以上；整体低对比度、偏暗（不要有大面积亮天空、雪地、白墙、水面反光）。
- 大量虚化 / 景深（远景山峦、雾气、竹林虚影），高频细节别铺满全屏。
- 四周轻微暗角，中间偏左留出较空旷的区域（侧栏和会话正文都压在这块）。
- 色调统一（墨青、黛蓝、暗金），不要文字、水印、logo。
- 参考风格：写实武侠 / 水墨 / 胶片颗粒感的暗调画面。

可直接用的提示词：

```text
生成一张 16:9 的写实武侠风格背景图，用作深色 UI 壁纸。
整体低对比度、暗调（深蓝黑到墨青，#0b0d12～#1a1f2b），亮度不超过中灰；
大面积虚化与景深，远处山峦、雾气、竹林只留虚影，避免密集高频纹理；
不要明亮天空、雪地、白墙、水面反光等大面积高光；
四周轻微暗角，画面中心偏左留出较空旷区域，方便叠加文字；
色调统一，墨青与暗金点缀，不要人物正脸特写；
不要任何文字、水印、logo；胶片质感，轻微颗粒。分辨率 2560x1440 以上。
```

调参经验：深色主题 + 深色遮罩最稳；一般 `面板 65–80%`、`遮罩 35–55%`。想让图更清楚就降面板、加遮罩（保住对比），只降面板会重新看不清字。

## 已知限制

- 背景媒体走 IndexedDB，容量受浏览器配额限制（通常远大于 localStorage）；IndexedDB 不可用时（隐私模式等）背景仍能生效，但只保留到本次会话，界面会提示。
- 视频背景会持续解码，低配机器上可能增加 GPU/CPU 占用；切到后台会自动暂停。
- 背景透明化依赖宿主 CSS Module 局部名（`_centerCol` / `_sidebarCol` / `_frame` …）。DSH 若改了这些名字，背景页的「检测」按钮会显示命中 0 个容器，此时需要按新名字更新插件。
- 预设里带装饰的选择器（报纸、素描等）同样改用后缀匹配；宿主大改结构后可能失去装饰，但不会破版。
